## 9. 本轮新增与未覆盖说明

**新增自动化（2026-11-15）**

1. `/cww net flood <玩家> <次数>`：走 `nbw:hold` / `nbw:move` 接收器共用的 `NbwNetworking.admit`，
   在无真客户端时证明“限速接在入口上、跨秒重置”。**实测：1000→放行 40/丢 960；跨秒 10→10。**
   **边界**：不经过 Fabric 解码与网络传输，不能替代 wire-level 伪造包。
2. `security_probe.py` 增加：1000 包只过 40、跨秒重置、旁观者长按上限归零 + REJECT、
   钩竿隔墙/连点的当前口径测量（后者记 INCONCLUSIVE，待裁决）。
   **实测汇总：14 PASS / 0 FAIL / 2 INCONCLUSIVE。**

**物品复制代码审查结论（B-80）**

- 产出设施（过滤器/厨台/堆肥/医疗箱）用 `insertStack` 发放，背包满时物品**丢失**，不复制。
- 补给箱由服务端按稀有度直接填 `Inventory`，箱子是原版容器，破坏/开箱走原版逻辑。
- 扩建扣费在 `UseBlockCallback` 放置前扣，失败路径是**少放**而非多给；未发现“扣一次放两次”。
- 局后 `RoundManager` 清空参赛者背包；世界掉落物未做穷举（可能与跨局残留有关，不是复制）。
- **仍未自动化**：漏斗/发射器/死亡掉落/容器交互组合的穷举，需要专门的复制用例探针。

**本轮未跑（不冒充完成）**

- 真客户端伪造包、旁观者四条链路的真人复验（B-76/B-77）。
- 绳索/钩竿冷却与 LOS（B-78/B-79）——等用户裁决，见 `M5-ANTICHEAT.md §4`。
- 生产 jar 崩溃重启（B-93）与 48h 耐久（B-94）。
