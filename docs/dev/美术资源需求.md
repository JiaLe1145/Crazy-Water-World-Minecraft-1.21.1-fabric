## 五、优先级建议（共 **25 张**）

1. **筏心 + 残骸**（2 张）——玩家最需要一眼认出，且决定"要不要打"的判断
2. **弩炮弹**（1 张）——刚需，现在借的是原版箭
3. **三件设施武器**（弩炮 2 + 投石机 3 + 撞角 2 = **7 张**）——战斗时最常看
4. **生产设施 5 件**（过滤器/堆肥/厨台/医疗箱/发电机，各 2 张 = **10 张**）
5. **修理台 3 + 船桨 2**（**5 张**）
