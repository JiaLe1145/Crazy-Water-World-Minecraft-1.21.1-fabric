# 美术资源需求清单（规格版）

> 生成于 2026-11-21。**共 25 张贴图 + 12 个方块模型 + 1 个物品贴图**。
> 目标是可直接喂 `mcgen`：`spec.json` → `.bbmodel` + 16×16 贴图 + 等轴测预览。
>
> **风格基准**（写死，与 `docs/content/09` §6.2 一致）：
> - 设施类 → 仿 `AI建模/已做建模存储/电鳗发电机/` 的造型语言（`metal` / `crystal` / `plank` + `emissive`）
> - 物品类 → 仿原版武器贴图（16×16、斜置、木/铁既有配色、1px 深色描边）
> - 统一调色板：木质 `#8B6B47` / `#5C4630`，铁件 `#4A4A52` / `#8A8A93`，绳索 `#C4A675`，海水 `#2E6B8A`，警示 `#C0392B`

## 一、物品：弩炮弹（1 张）

| 项 | 规格 |
|---|---|
| 文件名 | `textures/item/ballista_bolt.png` |
| 尺寸 | **16×16** |
| 作用 | 弩炮的弹药，铁锭 + 2 木板 → 4 发；右键炮位装填，每发打 7♥ |
| 造型特点 | **粗短弩矢**，不是细长的原版箭。斜置 45°，箭头朝右上；头部是扁三棱铁头（占 4×4 像素），杆身 2px 宽、深木色，尾部两组燕尾羽（3px 高、向外张开）。**关键辨识点：铁头比原版箭大一圈**，玩家一眼要能和普通箭区分 |
| 现在用的占位 | `minecraft:item/arrow`（太细，容易看混） |

## 二、方块（12 个）

每个方块模型走 `cube_column`（`side` / `end` 两槽）或 `cube_bottom_top`（`side` / `top` / `bottom` 三槽）。

### 2.1 筏心 `raft_core` —— **优先级最高**

| 项 | 规格 |
|---|---|
| 作用 | 每队命脉，被打爆即全队出局；投石机/撞角的唯一目标 |
| 玩家怎么"读"它 | 大老远一眼要认出来"这家还能不能打" |
| 造型特点 | **必须完全不像任何原版方块**。建议：深色木格栅外框（4 边各 3px 厚）+ 中央 6×6 的发光核心；四角各一颗铁质铆钉。发光部分用 `emissive`，亮度接近海晶灯但不刺眼 |
| 配色 | 木框 `#3A2E22`；核心 `#E8C66A`（暖金）→ 边缘渐变到 `#B8860B`；铆钉 `#8A8A93` |
| 动画/变体 | 可选：核心做 4 帧循环呼吸（`sail_canvas` 那种多贴图切帧已有先例） |
| 现在用的占位 | `minecraft:block/beacon`（金色，**最容易和场景里其他金色方块看混**） |

### 2.2 筏心残骸 `raft_core_wreckage`

| 项 | 规格 |
|---|---|
| 作用 | 筏心被打爆后的残骸方块，标记"这家已经没了" |
| 造型特点 | 同样木格栅框，但**核心熄灭**：中央换成焦黑的破洞，框体开裂（2-3 条 1px 深裂缝贯穿），铆钉生锈发暗 |
| 配色 | 木框 `#241C14`（近乎炭化）；破洞 `#0E0E0E`；裂缝 `#4A2F1A`；锈 `#6B4A3A` |
| 关键约束 | **和筏心共享同样的外轮廓**——玩家靠"亮/灭"区分，不靠外形 |
| 现在用的占位 | `minecraft:block/cracked_stone_bricks` |

### 2.3 弩炮 `ballista`

| 项 | 规格 |
|---|---|
| 作用 | 32 格自动打最近敌人，7♥/发，需电 + 弹药 |
| 造型特点 | `side`：木质支架 + 两侧铁制弩臂（弩臂要做成向外张开的弧形，占满高度）；`end`：俯视的弩槽 + 绷紧的弦（1px 浅色横线横贯）。建议 `end` 加一点金属反光高光 |
| 配色 | 木架 `#8B6B47`；铁件 `#4A4A52`；弦 `#D8CBAA` |
| 现在用的占位 | `stripped_spruce_log` / `iron_block` |

### 2.4 投石机 `catapult`

| 项 | 规格 |
|---|---|
| 作用 | 40 格拆家，打敌方筏心 12♥；落点 4 格内敌方玩家吃 40% 伤害 |
| 造型特点 | 三槽：`side` 画木架与绞盘；`top` 画**投石臂 + 石弹筐**（这是识别关键，要让玩家俯视就能看出"这玩意会砸我"）；`bottom` 保持素木 |
| 配色 | 木架 `#7A5A38`；石弹 `#7A7A7A`；铁件 `#4A4A52` |
| 现在用的占位 | `stripped_oak_log` / `cobblestone` / `oak_planks` |

## 五、优先级与产出顺序

| 批次 | 内容 | 张数 | 理由 |
|---|---|---|---|
| **第 1 批** | 筏心 + 残骸 + 弩炮弹 | **3** | 决定"打不打这家"的判断依据，且弩炮弹是刚需 |
| **第 2 批** | 弩炮 / 投石机 / 撞角 | **7** | 战斗时最常看，辨识度直接影响交战胜负 |
| **第 3 批** | 过滤器 / 堆肥 / 厨台 / 医疗箱 / 发电机 | **10** | 生产链，中期才频繁接触 |
| **第 4 批** | 修理台 / 船桨 | **5** | 低频，可最后补 |

**合计 25 张**（1 张物品 + 24 张方块）。

> 建议先出第 1 批的 3 张作**风格锚点**给你过目，通过后再批量——避免 25 张做完风格全否。
